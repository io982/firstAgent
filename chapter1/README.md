# Глава 1: Базовый агент с ReAct-паттерном

## Что внутри

Простой агент с 4 инструментами:
- 🧮 Калькулятор (безопасный, через AST)
- 📁 Список директории
- 📄 Чтение файла
- 🔍 Поиск в файле

## Запуск

```bash
# Из корня проекта
python -m chapter1.agent
```

## Примеры запросов

```text
Вы > Посчитай (15 * 7) + 3
Вы > Покажи файлы в текущей папке
Вы > Найди в chapter1/agent.py слово calculator
```
