# Правила работы над курсом

## Оформление главы

У каждой главы есть папка `chapterN` и внутри неё `README.md` — это и есть
текст главы. Код главы лежит в `chapterN/agent.py` и `chapterN/src/`,
тесты — в `chapterN/tests.py`.

В конце текста каждой главы обязателен раздел «Итог главы». Его структура
всегда одна: что агент научился делать → чего он ещё не умеет → какой из
этих недостатков открывает следующую главу.

Ссылки вперёд, на главы с бо́льшим номером, давать нельзя: они ведут на
ненаписанное и ломаются на GitHub. Ссылки назад и на общий план разрешены.

## Числа берутся из кода

Главное правило работы с текстом: любое число, сниппет и имя в тексте главы
должны быть взяты из кода, а не по памяти. Основной источник ошибок в курсе —
не баги, а расхождение текста с кодом после рефакторингов: устаревшие числа
бюджета, сниппет с неправильной ролью сообщения, таблица, описывающая
несуществующий код.

Правя главу, пересчитывайте числа скриптом, который импортирует настоящие
функции, а не переписывайте их из прошлой версии текста.

## Проверки

Линтер — `ruff`, конфигурация в `ruff.toml`. Проверка длины строки отключена
намеренно: в коде много системных промптов на русском, и перенос по границе
делает их менее читаемыми.

Быстрые тесты запускаются командой `python -m pytest chapterN/tests.py -q`
и не требуют запущенной Ollama. Интеграционные тесты помечены меткой
`integration`, требуют живой модели и по умолчанию пропускаются. Есть ещё
метка `slow` — это статистические тесты на много вызовов модели.

Скрипт `ci_smoke.py` прогоняет быстрые тесты всех глав разом. Он же крутится
в CI на Python 3.10 и 3.13 вместе с линтером и компиляцией всех модулей.
Ollama в CI нет, поэтому там проверяется только то, что работает без модели.

## Git

Работа идёт прямо в ветке `main`, без веток и pull request'ов. Push делается
только по явной просьбе, а не после каждого коммита.

## Переменные окружения

- `AGENT_MODEL` — какая модель отвечает, по умолчанию `qwen2.5:3b`.
- `AGENT_NUM_CTX` — размер контекстного окна: 4096 в главах 1–3, 8192 в Главе 4.
- `AGENT_STRUCTURED=0` — выключить constrained decoding.
- `AGENT_MCP` — подключить инструменты с MCP-сервера.
- `AGENT_EMBED_MODEL` — модель эмбеддингов, по умолчанию `nomic-embed-text`.
- `AGENT_VECTOR_STORE` — хранилище векторов: `chroma` по умолчанию, `memory` — перебор в памяти.
- `AGENT_DOCS_DIR` — папка с документами для базы знаний.
