# Глава 3: Контекст, память и производительность

## Что внутри

Агент из Главы 1 с памятью между запросами:
- 💾 История диалога сохраняется между запросами
- ✂️ Обрезка истории до `MAX_HISTORY` сообщений
- 🧹 Команды `/reset`, `/clear`, «очистить» сбрасывают память
- 📏 `num_ctx = 8192` — окно под историю диалога
- ⚡ `keep_alive = "5m"` — модель в памяти

## Запуск

```bash
# Из корня проекта
python -m chapter3.agent
```
